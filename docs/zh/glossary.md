# 术语表

中英文文档共用这一份术语表。新增术语时，两种语言的表都要更新。

| 英文 | 中文 | 含义 |
| --- | --- | --- |
| user guide | 使用指南 | 写给使用者的那部分文档。 |
| developer guide | 开发指南 | 写给开发者的那部分文档。 |
| agent guide | Agent 指南 | 写给 AI agent 的那部分文档。 |
| MCP server | MCP 服务器 | 通过 Model Context Protocol 向 agent 提供文档的程序。 |

:::{admonition} 模板占位
补上你的项目里的术语。
:::
